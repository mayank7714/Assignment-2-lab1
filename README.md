# Assignment: Portfolio Website

A simple, single-page personal portfolio website built with **HTML** and **CSS** as a beginner web development assignment.

## Overview

The page introduces the person behind the portfolio and is split into four sections, linked from a navigation bar at the top:

- **About Me**: profile picture and a short introduction
- **My Skills**: a table of skills and current levels
- **My Projects**: cards describing mini projects
- **Contact Me**: a form with name, email, and message fields

A **Back to Top** button stays fixed in the bottom-right corner for quick navigation.

## Features

- Sticky navigation bar with smooth scrolling to each section
- Skills table with a styled header row
- Project cards with rounded corners
- Contact form built with a table layout
- Responsive on small screens
- HTML and CSS kept in separate files

## Tech Used

- HTML5
- CSS3
- [Poppins](https://fonts.google.com/specimen/Poppins) font from Google Fonts

## Project Structure

```
Assignment-resume/
├── index.html      # Page structure and content
├── style.css       # All styling
├── images/
│   └── avatar.svg  # Profile picture (replace with your own)
└── README.md
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/mayank7714/Assignment-resume.git
   ```
2. Go into the folder:
   ```bash
   cd Assignment-resume
   ```
3. Open `index.html` in any web browser.

## Customize

- Replace the name and intro text in the **About Me** section of `index.html`.
- Swap `images/avatar.svg` for your own photo, and update the `src` in `index.html`.
- Edit the skills table rows and project cards to match your own.
- Change the theme color by editing `--blue` at the top of `style.css`.
